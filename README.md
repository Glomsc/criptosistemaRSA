# RSA Crypt/Decrypt - Projeto de Criptografia

## **Descrição**
Este é um sistema simples de criptografia e decriptação usando o algoritmo RSA implementado do zero em Python que possui interface web com Flask e páginas HTML estilizadas com TailwindCSS.

#### Ele permite:

- Gerar chaves públicas e privadas automaticamente ou manualmente.
- Criptografar textos.
- Decifrar mensagens criptografadas.


## **Funcionalidades**

- Criptografia: transforma textos em mensagens cifradas usando chaves RSA.
- Decifragem: recupera o texto original a partir do texto cifrado.
- Salvamento automático de chaves: as chaves geradas na criptografia são salvas no navegador e usadas automaticamente na decifragem.
- Interface web: fácil de usar, com botões para navegar entre os módulos.


## **Tecnologias utilizadas**

Python 3
Flask
HTML / CSS (TailwindCSS)
Javascript


## **Como usar**

1. Instale o Python 3.11 ou superior.
2. Instale o Flask: utilize o comando "pip install flask"
3. Execute o servidor: utilize o comando "python server.py"
4. Abra o navegador e acesse: http://127.0.0.1:5000/
5. Use os módulos para criptografar e decifrar textos.
